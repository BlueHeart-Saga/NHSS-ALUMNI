# Event-Day Operational Readiness Checklist & Venue Checklist

## 1. Overview
This operational readiness checklist outlines pre-event, during-event, and post-event actions for **ABC School** get-together reunions.

---

## 2. Event-Day Execution Checklist

### Phase A: Pre-Event Readiness (T-3 Hours)
- [ ] **Venue Wi-Fi & Mobile 4G/5G Tested**: Verify dual network connections at check-in desk.
- [ ] **Scanner Station Power**: Ensure check-in tablet/laptop battery is 100% and plugged into power.
- [ ] **Admin & Coordinator Logins Tested**: Verify staff can log in to `http://admin.abcschool.edu`.
- [ ] **Event Published & Capacity Locked**: Confirm event status is `PUBLISHED` with capacity set to `300`.
- [ ] **Test Ticket Scan**: Perform test scan to verify instant green **CHECK-IN SUCCESSFUL** notification and duplicate alert.

### Phase B: On-Site Check-In Execution (Event Hours)
- [ ] **QR Check-in Station Active**: Staff scans arriving alumni mobile screen tickets.
- [ ] **Manual Lookup Active**: If alumnus battery dies or phone is missing, staff searches full name or admission number in Manual Lookup.
- [ ] **Duplicate Block Active**: Attempted re-scans trigger red **ALREADY CHECKED IN** alert screen.
- [ ] **Live Dashboard Monitoring**: Real-time counter displays Expected vs. Checked In vs. Remaining.

### Phase C: Post-Event Wrap-Up
- [ ] **Export Final Attendance CSV**: Download spreadsheet with timestamps and guest breakdown.
- [ ] **Mark Event Completed**: Update event status to `COMPLETED`.
- [ ] **Broadcast Photo Upload Request**: Send announcement asking alumni to upload reunion photos.
